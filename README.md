# 📘 StudyFlow

A simple task and deadline tracker for students. Keep track of assignments across subjects and see what's due next.

## Main Features
- Dashboard with task stats and a completion progress bar
- "Due Soon" list sorted by date
- Add, edit and delete tasks with subject, due date, priority and notes
- Mark tasks complete / pending
- Search, and filter by subject or status
- Due-date indicators (Due today, Overdue, In Xd)
- Data saved in your browser with LocalStorage
- Responsive design with modal forms and toast messages

## Technologies
HTML5, CSS3, Vanilla JavaScript, LocalStorage

## How to Run
Open `index.html` in any modern browser. No install or server needed.
